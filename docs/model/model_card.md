# Model card — BikeFlow MLP embedding

## Назначение и артефакт

Модель прогнозирует суммарное число аренд велосипедов в Сеуле за один час при
заданной пользователем погоде. Она не получает погоду сама и не предназначена
для отдельных станций или других городов.

Production-артефакт `models/model.joblib` содержит единый `InferencePipeline`:
валидацию, preprocessing, числовой scaler и обученную CPU PyTorch MLP с
embedding-кодированием категорий. API читает путь из `BIKEFLOW_MODEL_PATH`.

Признаки: `hour`, `day_of_week`, `season`, температура, влажность, ветер,
видимость, точка росы, солнечная радиация, дождь, снег и праздник.
`is_functioning=false` возвращает ровно ноль. Общий контракт определён в
`bikeflow.ml.features.FEATURE_CONTRACT`.

## Выбор модели

Все модели — baseline, HGB и две MLP — участвуют в трёх rolling-origin folds.
Каждый fold обучается только на прошлом и оценивается на следующем периоде.
Код отклоняет fold, пересекающий test.

| Модель | Apr–May | Jun–Jul | Aug–Sep | средний MAE | худший fold |
| --- | ---: | ---: | ---: | ---: | ---: |
| **mlp_embedding** | 407.2 | 378.0 | 379.2 | **388.1** | **407.2** |
| hgb | 579.6 | 469.5 | 200.2 | 416.4 | 579.6 |
| mlp_onehot | 480.2 | 358.8 | 439.3 | 426.1 | 480.2 |
| seasonal_median | 689.9 | 867.3 | 644.1 | 733.8 | 867.3 |

HGB выигрывает только последний fold и одиночное Aug–Sep validation-окно, но
хуже MLP embedding по среднему MAE и стабильности. Поэтому production-модель —
MLP embedding; HGB остаётся сравнительной моделью.

Основная метрика — **MAE** в арендах/час. **WAPE** (`Σ|y−ŷ| / Σy`) —
дополнительная масштабно-нормированная метрика. Test не используется ни для
выбора, ни для early stopping: его метрики рассчитываются после выбора только
для production-модели.

Результаты полного запуска и точные значения находятся в `reports/metrics.json`
и `reports/model_selection.md`; CV повторяется командой
`python -m bikeflow.ml cv`.

## Воспроизводимость

Загрузчик проверяет SHA256 датасета. В metadata сохраняются `model_version`, Git
SHA, seed 42, параметры, SHA256 данных/конфигурации и версии Python, NumPy,
pandas, scikit-learn и PyTorch. Детерминированные алгоритмы и закреплённые версии
снижают вариативность, но bit-for-bit идентичность независимых запусков на разных
ОС и аппаратных платформах не гарантируется.

## Ограничения

- Один год данных и один агрегированный счётчик для Сеула.
- Test полностью осенний; осень отсутствует в train как категориальный уровень.
- Пики спроса часто недооцениваются; редкие дождливые режимы нестабильны.
- Нет лагов спроса, автоматического weather API, мониторинга и retraining.
- Это учебный прогноз, не гарантия наличия велосипедов.
